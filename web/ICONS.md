# Icons

The file `sprite.svg` contains the interface icons of the portal chrome. These icons are the theme selector, sign out, settings, warning and back icons. The project copies the icons verbatim from Tabler Icons v3.49.0, outline set (MIT, Copyright (c) 2020-2026 Paweł Kuna, https://github.com/tabler/tabler-icons, tag `v3.49.0`, commit `bbed884d15354b5cebf2493371f20dc2d5e83eaf`). The icons are: `device-desktop`, `moon`, `sun`, `logout`, `settings`, `alert-triangle`, `chevron-right`, `chevron-down`, `arrow-left`, `refresh`, `plus`, `trash`, `copy`, `lock`, `x`, `ban`, `check`, `folder`, `pencil`, `bell`, `bell-ringing`, `key`, `device-mobile`, `device-mobile-off`, `clock`, `circle-check`, `search`, `send`, `book`, `user-share`, `activity`, `inbox`, `webhook`, `robot`, `user`, `users`, `help-circle`, `checkbox`, `point`, `tags`, `eye`, `eye-off`. The project does not draw any interface icon by hand. There is one exception: the two symbols of the logo, `logo` (the mark) and `logo-lockup` (the mark and the word). They come from `assets/brand/` and have no licence of a third party, except the typeface that the word outlines (see the README of that folder). The portal does not fetch any icon at runtime.

The sprite has one `<symbol>` for each line. Each page inlines only the symbols that it draws. The page does not use an external `<use>`. So there is no icon request, and no unused node in the page. The error pages draw no symbols. No sign-in page draws a symbol of the logo. The sign-in page draws four: `lock`, `alert-triangle`, `eye` and `eye-off`. The card of the second step draws the first two. The launcher draws six symbols: the lockup and the mark of the logo, and the four of the controls. It draws seven with the gear. A settings page draws the mark of the logo (`logo`) with its other symbols. An account that receives notifications adds five more: `inbox`, `x`, `alert-triangle`, `bell` and `bell-ringing`. The settings pages add the same toast symbols. The comment about origin is in this file, not in `sprite.svg`. So the browser does not receive the comment.

Service icons are a separate subject. They are in the embedded offline library. Refer to the catalogue documentation.

The symbol `logo` has no colour literal. The stroke is `currentColor`, and the circle has the class `logoDot`, which the stylesheet colours with `--logo-dot`. The rule of the stylesheet applies inside the shadow tree of the `<use>` element, and the custom property passes into it, so the dot follows the theme.

Inbox

Interface sans mot de passe : toute personne qui accède à ce port peut envoyer des alertes et révoquer des appareils. Exposez-la uniquement en local, sur un réseau privé ou derrière un proxy authentifiant.

Hôte non autorisé

Le serveur refuse les requêtes adressées à (protection contre le DNS rebinding).

Ajoutez cet hôte, port compris, à admin.allowed_hosts dans la configuration du serveur, puis redémarrez-le. Exemple : 

admin {
  allowed_hosts = ["localhost:8081", "127.0.0.1:8081"]
}

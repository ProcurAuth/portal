Hôte non autorisé. Ajoutez à admin.allowed_hosts dans la configuration du serveur, ou déclarez le reverse proxy dans server.trusted_proxies, puis redémarrez Inbox.

Intégrations

Brancher Grafana, Alertmanager ou n'importe quel outil d'alerting sur Inbox. Les alertes partent de l'outil vers Inbox, puis vers les téléphones abonnés : elles sont à sens unique.
